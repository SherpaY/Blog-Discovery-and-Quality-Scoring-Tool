Results appear here after a scan is published. To run one:

  1. On GitHub, open Actions → Daily blog scan → Run workflow (or wait for the daily run).
  2. When it finishes, the results are committed to site/data/ and this page updates after Vercel redeploys.

Or run python -m scanner scan then python -m scanner publish on your Mac and push the changes.
